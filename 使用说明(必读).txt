LiteMonitor 使用说明（必读）

一、简介
LiteMonitor 是一款轻量、可定制的 Windows 桌面硬件监控软件，实时监测 CPU、GPU、内存、磁盘、网络等系统性能。

二、运行环境
- Windows 10 / 11
- 需要 .NET 8 运行时（本项目已内置对应依赖时无需额外安装）

三、启动
解压后运行 LiteMonitor.exe 即可。软件会自动根据系统语言加载对应语言文件。

四、主要功能
- CPU / GPU / 内存 / 磁盘 / 网络 / 温度 / 风扇等实时监控
- 横屏 / 竖屏 / 任务栏 / 网页显示模式
- 主题切换、透明度、多语言、三色报警
- 每日流量统计、网络测速、内存清理、自定义插件
